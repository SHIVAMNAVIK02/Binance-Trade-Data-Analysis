## Binance Trade Data Analysis & Ranking


# Overview
# This project analyzes historical Binance trade data to rank accounts based on key financial metrics.

# Key Features

Performance Metrics: ROI, Sharpe Ratio, Win Rate, MDD, Total Positions
Trade Classification: Identifies long/short positions
Feature Importance: Correlation analysis of key metrics
Ranking System: Weighted scoring for top 20 accounts
Files & Outputs
calculated_metrics.csv – Full dataset with computed metrics
top_20_accounts.csv – Ranked top 20 accounts
summary_report.csv – Statistical summary of performance

# Tech Stack

Python (Pandas, NumPy, Seaborn, Matplotlib)
